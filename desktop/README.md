# Avatar Forge Desktop · 1.0.0

Windows 数字人口播工作台：Lab设备登录、图片/人物视频输入、声音克隆/已有音频、模特与音色管理、已有资产复用、暂停恢复、成片网格与导出。供应商密钥留在服务端，只交付最终zeroshot视频。

`node --test tests/*.test.cjs` 验证客户端逻辑。正式发布前先部署Lab资产库接口，再发布安装包及更新清单。Windows安装包暂未签名，保留预览期appId和用户目录以兼容登录与任务数据。资产库显示最近200项，旧记录可补充原图封面。

## 历史开发记录（不代表1.0.0当前功能）

当前源码正在开发1.0.0，新增真实分阶段制作、设备授权、暂停恢复、最终视频与云端历史、导出和更新。尚未正式部署或完成真实媒体验收；下方0.1.x是历史本地预览包说明，不代表当前源码已发布。

独立 Electron 桌面交互原型，放在原 Skill 仓库 `desktop/`，不修改 Skill 的运行链路。

`npm install` 后 `npm start` 启动桌面窗口。也可 `node preview.cjs` 在 http://127.0.0.1:3291 预览同一套界面。

已实现本机图片/视频/声音选择与拖放、素材预览、输入分支、文案与授权校验、明确标记的流程模拟、历史空态和登录说明。

0.1.1已实现独立Lab桌面授权客户端，须先部署配套Lab 0.5.6-dev后才能正式登录。PKCE、设备令牌加密存储、刷新和退出均在主进程，浏览器预览不可登录。服务端未发布，尚未真实用户端到端验收。生成、历史、下载和更新源尚未接入；模拟结束不产生媒体，不写入云端。不得将原始素材预览标作生成结果。

本地Windows预览安装包：`release/Avatar-Forge-0.1.0-Preview-Windows-x64-Setup.exe`。已完成NSIS构建和打包程序启动检查，未验证干净机器安装，尚无发布者签名。安装目录可选择，无需自行安装Node/Python。该包只用于预览，不是已接入云端的正式业务版本。

后续授权需独立注册 Avatar Forge 桌面 clientId/回调协议，复用 Lab PKCE、设备令牌、刷新/撤销，并为 Avatar 接口添加桌面身份认证。不得冒用 CineSleuth clientId，不下发供应商凭据。

图片用内置固定短音频生成模板；人物视频直接快速克隆。参考声音+文案合成目标口播，已有口播音频直接推理；最终只交付平台 zeroshot 产物。任务 ID 必须持久化，未知状态优先查询，禁止盲重试。
